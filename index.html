项目排序：

荧光蛋白：高亮度 + 热稳定性联合优化（AI 设计与筛选）

Protein Language Model · Regression · Mutation Generation · Screening
  • 使用预训练蛋白质语言模型 ESM 对荧光蛋白序列进行高维编码，捕捉进化与结构特征。

Vector Retrieval · Benchmark · Query Rewrite · Debug Tooling
  • 基于开源 RAG 项目构建学术论文问答系统，并使用自建 benchmark 做性能评估与迭代优化。
  • 修复相似度计算问题，将向量库距离计算修正为余弦相似度以提升检索准确性。

Agentic Workflow · LLM · Validation Gates · Benchmark · Traceability

细菌博弈赛：大肠杆菌运动能力多级调控强化

Promoter engineering · Transcriptional regulation · Sigma28 overexpression · Motility assay
  • 通过将序列元件 IS5 整合至 flhD 操纵子调节区，干扰 OmpR 和 RcsB 等负调控因子的结合位点，解除转录抑制并提升 flhD 起始转录水平。
  • 构建由高效 T7 启动子驱动的 sigma28 高表达质粒，实现鞭毛特异性 σ 因子增强表达，从而强化大肠杆菌在软琼脂培养基中的运动能力与趋化响应。
  • 采用 RT-qPCR 对相关基因表达水平进行定量检测，并结合运动环直径测定完成表型验证，形成干湿实验闭环；最终显著提升菌株在群体竞争中的运动优势，并获得中国合成生物学竞赛银奖。

我在 AI4S 中的关注点

From Representation to Prediction, Design, and Verification Loop
核心闭环（适用于生命科学）
  • 表征：序列/结构到 embedding（如 ESM）。
  • 预测：性质/表型到回归/分类模型（如 XGBoost）。
  • 设计：突变/生成策略与约束联合优化（如热稳定性偏好）。
  • 验证：筛选与实验验证（wet lab / in silico）。
  • 迭代：评测驱动的误差分析与数据/策略更新。

我倾向于把科研目标拆成可复现 pipeline，并用评测指标推动迭代，而不是只做一次性 demo。

竞赛与奖项（含详细介绍）

全国大学生数学建模竞赛 · 山东省二等奖（案例 1：半导体外延层厚度反演）

全国大学生数学建模竞赛 · 山东省二等奖（案例 2：电子制造成本-质量-利润优化）

  • 简单场景采用遍历法验证，复杂多工序系统开发基于遗传算法的 MATLAB 求解器。
  • 引入关系系数 alpha 并做灵敏度分析，验证真实次品率波动条件下最优决策稳定性。
